# Rallyism App
    - Rallyism is a Next.js + Expo app for creating a personal rally memories gallery with photos, albums and YouTube video links. The app is focused on rally events, rally trips, photo viewing, simple media filtering and preserving motorsport memories in a clean visual format.
    - Workspace 'rallyism-web': Next.js-based back-end + Web front-end
    - Workspace 'rallyism-mobile': Expo-based mobile client app
